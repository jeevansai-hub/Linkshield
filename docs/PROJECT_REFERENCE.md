## 1. System Architecture & Component Boundaries

LinkSentinel is designed as a decoupled, modular Machine Learning system for real-time URL risk classification. 

### Data Flow Diagram

```text
[ Raw Input URL String ]
           │
           ▼
┌──────────────────────────────────────────────┐
│  src/features/extract_features.py            │
│  - Lexical Analysis (length, counts)         │
│  - Host & Domain Breakdown (TLD, IP presence)│
│  - Security Marker Check (HTTPS, Susp Words) │
└──────────────────────┬───────────────────────┘
                       │
                       ▼ Feature Vector (Dictionary / DataFrame)
┌──────────────────────────────────────────────┐
│  src/models/train_evaluate.py                │
│  - Feature Scaler & Preprocessor             │
│  - Machine Learning Classifier               │
└──────────────────────┬───────────────────────┘
                       │
                       ▼ Probability Vector [P(Safe), P(Suspicious)]
┌──────────────────────────────────────────────┐
│  src/utils/metrics.py & Output Gateway       │
│  - Decision Thresholding (Default: t = 0.50) │
│  - 5-Metric Evaluation (Acc, Prec, Rec, F1,  │
│    ROC-AUC)                                  │
│  - Risk Tag Output ("Safe-Looking" /         │
│    "Suspicious")                             │
└──────────────────────────────────────────────┘
```

## 3. Feature Definitions Schema

Every feature extracted by `URLLexicalFeatureExtractor` MUST be strictly static and documented in this schema:

| Feature Name | Type | Extraction Logic / Description | Threat Rationale |
| :--- | :--- | :--- | :--- |
| `url_length` | `int` | Total character count of full URL string. | Phishing URLs often use long URLs to hide hostnames. |
| `hostname_length` | `int` | Character length of extracted netloc/hostname. | Long subdomains are common in brand impersonation. |
| `path_length` | `int` | Character length of URL path component. | Obfuscated paths often contain token strings. |
| `num_dots` | `int` | Count of `.` characters in URL string. | Multiple subdomains (e.g. `paypal.com.attacker.com`). |
| `num_hyphens` | `int` | Count of `-` characters in hostname. | Phishing domains frequently use hyphenated keywords. |
| `num_underscores` | `int` | Count of `_` characters in URL string. | Used in obfuscated path/query tokens. |
| `num_slashes` | `int` | Count of `/` characters in URL string. | Deep path hierarchies mask payload scripts. |
| `num_question_marks` | `int` | Count of `?` characters in URL string. | Multi-query parameter injection. |
| `num_equal_signs` | `int` | Count of `=` characters in URL string. | Indicates dense query string parameterization. |
| `num_at_symbols` | `int` | Count of `@` characters in URL string. | Anything before `@` is treated as user info, masking host. |
| `num_digits` | `int` | Count of numeric characters (`0-9`) in URL. | Used in hex obfuscation or IP-based hosts. |
| `digit_ratio` | `float` | `num_digits / url_length` ratio. | High digit density indicates random token generation. |
| `has_ip` | `binary (0/1)` | RegEx match for IPv4/IPv6 address as hostname. | Attackers use raw IPs to bypass domain registration. |
| `is_https` | `binary (0/1)` | `1` if URL scheme is `https`, else `0`. | Basic security indicator (though phishing uses HTTPS too). |
| `has_shortener_domain` | `binary (0/1)` | Match against known shortener domains (`bit.ly`, etc.). | Shorteners conceal true destination domain. |
| `suspicious_keyword_count`| `int` | Count of suspicious terms (`login`, `bank`, `verify`, etc.). | Target social engineering lures in domain/path. |

## 4. Model Lifecycle & Versioning

1. **Baseline Phase**: Logistic Regression with `StandardScaler` to establish simple, explainable performance metrics.
2. **Ensemble Phase**: Random Forest, XGBoost, and LightGBM hyperparameter tuning.
3. **Artifact Serialization**: Trained models saved to `models/<model_name>_v<version>.joblib` alongside feature column manifests.
4. **Inference Latency Budget**: Benchmark execution MUST verify inference time per URL is `<50ms` (Target: `<10ms` for batch vectors).
